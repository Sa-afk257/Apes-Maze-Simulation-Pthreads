# Apes Collecting Bananas in a Maze Simulation

## Overview

This project simulates ape family behavior inside a maze using POSIX Threads.

Female apes collect bananas, male apes protect baskets, and baby apes attempt to steal bananas during conflicts. The simulation models energy consumption, competition, synchronization, and resource management in a concurrent environment.

## Features

* Multi-Threaded Simulation
* Maze Environment Generation
* Banana Collection
* Ape Family Interactions
* Energy Management
* Conflict Simulation
* Synchronization Mechanisms
* Shared Resource Protection
* Configurable Simulation Parameters

## Technologies Used

* C Programming
* POSIX Threads (Pthreads)
* Synchronization Primitives
* Mutexes
* Condition Variables
* OpenGL Visualization
